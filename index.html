放假 / 临时调整怎么做

  1. 点右上角或日历工具条上的「紧急重设基准」。
  2. 选一个日期，选这天由谁值日（默认自动跟随原轮值，不用改）。
  3. 「仅本机生效」→ 立刻重排日历，先自己用；「生效并下载 txt」→ 同时拿到 base_date.txt。
  4. 把下载的文件覆盖到仓库根目录，提交并推送，其他人刷新页面就跟上了。
  5. 万一搞错：点「撤销本机临时基准」，回到仓库文件的值；或者再重设一次。

直接双击打开 index.html（file://）时，浏览器不允许读取同目录的 .txt， 这时程序用内置默认值（26.11.1）。想让它读仓库文件，用本地服务 （python -m http.server）或部署到 GitHub Pages 打开。
